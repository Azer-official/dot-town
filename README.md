# 도트 타운 (dot-town)

브라우저에서 바로 즐기는 도트(픽셀) 게임입니다. 빌드 과정 없는 정적 사이트이며 GitHub Pages로 배포됩니다.

- 플레이: https://azer-official.github.io/dot-town/game/
- `game/` — 게임 본체 (index.html, JS, 에셋)
- `data/` — 뉴스·스토리·학습 데이터 (게임이 `../data/` 상대경로로 불러옵니다)
- `docs/` — 데이터 형식 등 문서

이 저장소는 배포 스크립트(`tools/deploy_pages.sh`)로 자동 갱신됩니다. 직접 수정하지 마세요.
